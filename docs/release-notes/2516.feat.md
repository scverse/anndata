{attr}`~anndata.AnnData.obs` and {attr}`~anndata.AnnData.var` are no longer restricted to {class}`pandas.DataFrame`.
Any dataframe [narwhals](https://narwhals-dev.github.io/narwhals/) supports — `polars`, `pyarrow`, `modin`, `cudf` and `dask` — can be passed and is kept in its own backend, with index-less backends carrying the axis names in an `obs_names`/`var_names` column.

The new {meth}`~anndata.AnnData.obs_as` and {meth}`~anndata.AnnData.var_as` return the annotation as a native dataframe of another backend.
A {class}`~anndata.experimental.backed.Dataset2D` is now dataframe-like to narwhals as well, so a lazily backed annotation answers the same queries without being read into memory.
