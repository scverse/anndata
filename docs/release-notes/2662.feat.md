With `compat="0.14"`, mapping keys like in `uns` and `obs`/`var` column names are stored in an array instead of as child names, so any string works as one, e.g. `a/b` ({issue}`2039`) or `a:b`. Dataframes follow the [zarr dataframe convention](https://github.com/scverse/zarr-convention-dataframe). {user}`flying-sheep`
