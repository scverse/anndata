With `compat="0.14"`, mapping keys like in `uns` and `obs`/`var` column names are stored in an array instead of as child names, so any string works as one, e.g. `a/b` ({issue}`2039`) or `a:b`. Dataframes follow the [zarr dataframe convention](https://github.com/scverse/zarr-convention-dataframe).

```{note}
This means children of such groups are no longer stored under their key: path access like `f["obsm/X_pca"]` or `sparse_dataset(f["layers/counts"])` raises a {exc}`KeyError`, and {func}`~anndata.experimental.read_dispatched` callbacks see e.g. `/obsm/item_0` instead of `/obsm/X_pca`. Code that accesses files directly needs to check the parent group’s `encoding-version` first.
```
