Categorical columns of an {func}`~anndata.experimental.read_lazy` object now carry a `LazyCategoricalDtype`, a {class}`pandas.CategoricalDtype` subclass that only reads the categories it is asked for.
`dtype.n_categories` is answered from storage metadata, `dtype.head_categories(n)`/`dtype.tail_categories(n)` do a partial read, and `dtype.categories` still loads (and then caches) the full {class}`pandas.Index`.
