Added two `compat="0.14"` features for faithfully writing more {attr}`~anndata.AnnData.uns` {smaller}`P Angerer`

- The `sequence` encoding: sequences that numpy cannot faithfully turn into an array – heterogeneous, ragged or nested ones – are written element by element, so arbitrary JSON-like structures with writeable leaves (scalars, arrays, {class}`~pandas.DataFrame`, {class}`~anndata.AnnData`, …) round-trip ({issue}`1979`). Any {class}`~collections.abc.Sequence` is writeable now, not just {class}`list`.
- The `accessor` encoding: {mod}`anndata.acc` accessors such as `A.obsm["pca"][0]` are stored as their {meth}`~anndata.acc.AdAcc.to_json` form.
