Object-dtype {class}`~pandas.DataFrame` columns (e.g. in {attr}`~anndata.AnnData.obs` and {attr}`~anndata.AnnData.var`) holding integers, booleans, or floats, with or without missing values, are now written as the matching nullable (`Int64`/`boolean`), `int64`/`bool`, or `float64` array instead of failing (`h5ad`) or being silently written as strings (`zarr`). Object columns that cannot be converted raise a {exc}`TypeError` naming the column, and columns without an on-disk encoding (nullable floats, datetimes, pyarrow-backed and other extension arrays) get a note naming the column, its dtype, and what to convert it to; see the new {ref}`type mapping table <type-mapping>` {user}`zboldyga`

Categoricals whose categories are intervals, periods or tz-aware datetimes now raise a {exc}`TypeError` when written instead of failing inside h5py (`h5ad`) or being silently written as strings (`zarr`) {user}`zboldyga`
