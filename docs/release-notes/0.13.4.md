### 0.13.4 {small}`2026-09-18`

#### Miscellaneous changes

- The {mod}`zarr` format v2 writing is now deprecated via `anndata.settings.zarr_write_format` and this setting will be removed in 0.14 {user}`ilan-gold` ({pr}`2628`)

#### Bug fixes

- Fall back to copying via `asarray` when moving arrays between Array API namespaces fails with a {exc}`BufferError`, e.g. for implementations that don’t support DLPack 1.0 {user}`amalia-k510` ({pr}`2561`)
- Remove hard-coded scheduler when writing dask arrays to zarr stores {user}`joshua-gould` ({pr}`2584`)

#### Performance

- Use the new [`FusedCodecPipeline`][] where we control reading/writing to a zarr store if {doc}`zarrs-python <zarrs:index>` is not installed i.e., {mod}`zarr` i/o {user}`ilan-gold`

  [`FusedCodecPipeline`]: https://zarr.readthedocs.io/en/stable/user-guide/experimental/#fusedcodecpipeline ({pr}`2529`)
